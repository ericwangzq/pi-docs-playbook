Pi 架构层次图

pi-agent-core → coding-agent → extension / skill / SDK / RPC

🔌
用户接口层
各种接入方式

提供多种方式接入 Pi 的 agent 能力，从简单的配置到完整的编程接口

🧩
Extension
TypeScript 模块
  • 注册自定义工具
  • 监听/拦截事件
  • 自定义 UI 组件
  • 覆盖内置工具
📚
Skill
Markdown 文件
  • 按需加载的能力包
  • 遵循 Agent Skills 标准
  • /skill:name 调用
  • 封装工作流程
💻
SDK
TypeScript API
  • 编程方式调用 Pi
  • 完整 API 访问
  • 构建自定义 UI
  • 集成到现有应用
🌐
RPC
JSON-RPC 协议
  • 跨语言集成
  • 进程隔离
  • stdin/stdout 通信
  • 语言无关客户端
🤖
Coding Agent
@earendil-works/pi-coding-agent

编码 Agent 实现，提供完整的编码工具集、会话管理、模型管理和资源加载能力

🛠️ Tools
read, write, edit, bash, grep, find, ls
💬 Sessions
JSONL 存储, 树结构, 分支, 压缩
🧠 Models
认证, 注册表, Provider, 思考级别
⚙️ Settings
全局设置, 项目设置, 配置覆盖
📦 Resources
Extensions, Skills, Prompts, Themes
🖥️ TUI
交互界面, 命令, 快捷键
⚡
Agent Core
@earendil-works/pi-agent-core

Agent 核心框架，实现 LLM 交互循环、消息管理、工具调用和状态管理

🔄 Agent Loop
LLM 交互循环, 多轮对话
💬 Messages
消息管理, AgentMessage
🔧 Tool Execution
工具调用框架, 并行执行
📊 State
状态管理, AgentState
📡 Events
事件系统, Event Bus
📐 Context
上下文管理, 窗口控制
🧠
AI Toolkit
@earendil-works/pi-ai

AI 基础设施层，提供 Provider 抽象、模型定义、流式处理和认证管理

🔌 Providers
OpenAI, Anthropic, Google, etc.
📋 Models
模型定义, 能力发现
📡 Streaming
流式响应处理
🔑 Auth
API Key 管理, OAuth

🔄 数据流示例：用户输入 "部署到生产环境"

1
SDK/RPC 接收输入
session.prompt("部署到生产环境")
→
2
coding-agent 处理
加载 Skills、Prompt Templates，准备系统提示词
→
3
agent-core 执行 LLM 循环
发送消息给 LLM，执行工具调用，返回结果
→
4
pi-ai 处理 Provider 通信
选择 Provider，构建请求，流式接收响应
→
5
返回结果给用户
通过事件流返回部署结果
✓
