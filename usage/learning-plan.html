中文导读工作流（贯穿每个阶段，解决英文文档吃力）

1. 让 agent 把文档讲成中文：pi @source/.../某文档.md "用中文讲解核心概念，API 名称保留英文"，顺便练 pi。

2. 每读完一篇 doc，让 agent 产出中文笔记，存到 skill-draft/notes/（绝不写进 source/）。

3. 技术术语（tool_call / session / compaction / extension）保留英文，不翻译。

4. 先读 examples/ 里的代码（跨语言、直观），再读英文散文。

核心边界（贯穿所有阶段）

pi 负责：agent loop、tool calling、session、extension、RPC。 业务状态机、幂等、审批、审计 log、异常补偿——这些仍必须由你的应用自己设计。

主线项目：随阶段生长的能力栈

这 8 个阶段叠加在同一个「个人助手 agent」上：

A.阶段 0–2：跑通 pi + 用配置塑形成你的品味（零代码）
B.阶段 3–5：用 skill + extension 让它真正会做日常任务（coding）
C.阶段 6–7：SDK headless + 前端 + 多 agent，做成完整体验
